# Capturas de referencia

Claude Code usa estas imágenes para respetar la identidad de marca de PG (colores, logo, menú, estilo) mientras mejora el sitio. Guárdalas aquí con estos nombres (PNG, página completa):

| Archivo | Qué capturar |
|---|---|
| `home-desktop.png` | pgasesorias.cl completa, ventana de 1440px |
| `home-mobile.png` | pgasesorias.cl completa, vista de celular |
| `header-desktop.png` | Solo el header, desktop |
| `header-mobile-abierto.png` | Header móvil con el menú hamburguesa abierto |
| `footer-desktop.png` | Solo el footer, desktop |
| `catalogo-desktop.png` / `catalogo-mobile.png` | /vehiculos-en-venta |
| `ficha-desktop.png` / `ficha-mobile.png` | Una ficha de vehículo (ej. Toyota 4Runner) |
| `servicios.png`, `nosotros.png`, `contacto.png`, `vende.png`, `flota.png` | Cada página, desktop |

Cómo sacar capturas de página completa en Chrome:
1. Abre la página y presiona `F12` (o `Cmd+Opt+I` en Mac).
2. `Ctrl+Shift+P` (o `Cmd+Shift+P`) y escribe **"Capture full size screenshot"**.
3. Para la vista móvil, antes presiona `Ctrl+Shift+M` y elige un iPhone.
